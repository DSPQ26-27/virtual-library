# Biblioteca Virtual

Proyecto académico de biblioteca universitaria simulada.

## Objetivo del Sprint 1
Registro de estudiantes, inicio de sesión y consulta del catálogo.

## Tecnologías
- Backend: Java + Spring Boot (Spring Web, Validation, Spring Security, Spring Data JPA/Hibernate)
- Frontend: React + Vite
- Base de datos: PostgreSQL, migraciones con Flyway
- Gestión: GitHub Issues + GitHub Projects

## Organización prevista

frontend/  # Aplicación React
